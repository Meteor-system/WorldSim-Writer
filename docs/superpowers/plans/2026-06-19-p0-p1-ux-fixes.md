# P0/P1 UX 修复实施计划（精简）

> 设计来源：`docs/superpowers/specs/2026-06-19-p0-p1-ux-fixes-design.md`
> 流程：严格 TDD（先红后绿），每个任务一组失败测试 → 最小实现 → 跑绿。禁止 push/merge，不碰 cc-work。

**目标：** 修复一批 P0 + 低风险 P1 UX 问题：CORS 多源、中文网络错误映射、登录校验/loading、书架错误卡+重试、创建表单 select/聚焦/删除撤销。

**技术栈：** 后端 FastAPI + pytest（TestClient，内存 SQLite）；前端 Vite/React + Vitest + @testing-library。

---

## Task 1：后端 CORS 多源（P0-1）

**Files:**
- Modify: `backend/app/core/config.py`
- Modify: `backend/app/main.py`
- Modify: `backend/.env.example`
- Test: `backend/tests/test_cors.py`（新建）

设计：`Settings.frontend_origins`（alias `FRONTEND_ORIGINS`，默认空）。新增属性 `cors_allow_origins`：
- `FRONTEND_ORIGINS` 非空 → 逗号拆分去空白去重为主列表；否则回退 `[frontend_origin]`。
- 始终并入开发默认四项：`http://localhost:5173`、`http://127.0.0.1:5173`、`http://localhost:3000`、`http://127.0.0.1:3000`，去重保持顺序稳定。
- `main.py` 用 `allow_origins=settings.cors_allow_origins`。

测试：OPTIONS 预检带 `Origin: http://127.0.0.1:5173` + `Access-Control-Request-Method: POST` → 响应头 `access-control-allow-origin` == 该 origin；参数化四个开发 origin；Settings 单测多值优先/单值回退/去重/含默认项。

## Task 2：前端 api client 中文错误映射（P0-2）

**Files:**
- Modify: `frontend/src/api/client.ts`
- Test: `frontend/src/api/client.test.ts`（新建）

`friendlyStatusMessage(status, detail)`：401→`登录状态已过期，请重新登录`；>=500→`服务暂时不可用，请稍后再试`；其它→保留 `formatApiError` detail。`apiRequest` try/catch 包 fetch：`TypeError`/message 含 `fetch` → 抛 `无法连接服务器，请检查网络或稍后重试。`，DEV 追加 ` 开发提示：请检查 API_BASE_URL 或 CORS 白名单。`。保留 `error.status`。
